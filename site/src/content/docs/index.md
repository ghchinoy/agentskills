This is the documentation site for **`agentskills`**, the Go command-line tool in
[ghchinoy/agentskills](https://github.com/ghchinoy/agentskills).

:::caution[Not to be confused with]
Not to be confused with [agentskills/agentskills](https://github.com/agentskills/agentskills), the Agent Skills
standard's own repository — it publishes [agentskills.io](https://agentskills.io) — or with
[ghchinoy/agent-skills](https://github.com/ghchinoy/agent-skills), the same owner's catalog of agent plugins,
which targets the [Agent Plugins](https://agent-plugins.org) standard.
:::

## Documentation

- [User's Guide](./users-guide/) — building, configuring, authenticating and running the CLI.

Only the User's Guide is published here so far. The other five documents shipped in the CLI's
release archive are deferred to a later phase, each recorded in the site's deferral register; they remain in the
[repository](https://github.com/ghchinoy/agentskills) on GitHub. Documentation outside the release
archive — agent instructions, issue-tracker notes and test fixtures — is not published here and is
not covered by that record.
